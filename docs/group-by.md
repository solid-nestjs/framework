# GROUP BY Aggregations

The GROUP BY feature provides data aggregation across entities and relations,
available through both REST and GraphQL. Use `findAllGrouped()` for analytical
queries with COUNT, SUM, AVG, MIN, and MAX aggregations.

## GroupByRequest

A `GroupByRequest<T>` specifies which fields to group on and which aggregates to compute:

```typescript
export interface GroupByRequest<T = any> {
  fields?: GroupBy<T>;
  aggregates?: AggregateField[];
}

export interface AggregateField {
  field: string;                      // entity field to aggregate
  function: AggregateFunctionTypes;   // COUNT | SUM | AVG | MIN | MAX
  alias?: string;                     // output key (defaults to `${fn}_${field}`)
}
```

### GroupBy<T> Type

Each key takes `boolean` to enable grouping on that field. Nested relations use
the same boolean pattern recursively:

```typescript
type GroupBy<T> = {
  [K in keyof T]?: boolean | GroupBy<T[K]>;
};
```

Example:

```typescript
const groupBy: GroupBy<Product> = {
  category: true,
  supplier: { name: true },   // group by supplier.name
  active: true,
};
```

## Aggregate Functions

| Function | Description | Example |
|---|---|---|
| `COUNT` | Count of records in group | Products per category |
| `SUM` | Sum of numeric values | Total inventory value |
| `AVG` | Average of numeric values | Average price per category |
| `MIN` | Minimum value in group | Lowest price |
| `MAX` | Maximum value in group | Highest price |

## findAllGrouped()

The `findAllGrouped` method exists on every service generated by
`CrudServiceFrom` or `DataServiceFrom`:

```typescript
const result = await service.findAllGrouped(context, {
  groupBy: {
    fields: { category: true },
    aggregates: [
      { field: 'price', function: AggregateFunctionTypes.AVG, alias: 'avgPrice' },
      { field: 'stock', function: AggregateFunctionTypes.SUM, alias: 'totalStock' },
      { field: 'id', function: AggregateFunctionTypes.COUNT, alias: 'productCount' },
    ],
  },
  pagination: { page: 1, limit: 10 },
});
```

## GroupedPaginationResult

The return type wraps groups with pagination:

```typescript
export interface GroupedPaginationResult<T = any> {
  groups: GroupResult<T>[];
  pagination: PaginationResult;
}

export interface GroupResult<T = any> {
  key: Record<string, any>;       // grouped field values
  aggregates: Record<string, any>; // computed aggregate values
}
```

Accessing results:

```typescript
result.groups.forEach(group => {
  console.log('Category:', group.key.category);
  console.log('Avg Price:', group.aggregates.avgPrice);
  console.log('Count:', group.aggregates.productCount);
});

console.log('Page', result.pagination.page, 'of', result.pagination.pageCount);
```

## Grouping on Relation Fields

Group by fields from related entities. The relation structure mirrors the
`Where<T>` / `OrderBy<T>` nesting pattern:

```typescript
const result = await service.findAllGrouped(context, {
  groupBy: {
    fields: {
      supplier: { name: true },   // group by supplier.name via JOIN
    },
    aggregates: [
      { field: 'price', function: AggregateFunctionTypes.AVG, alias: 'avgPrice' },
    ],
  },
});

// group.key.supplier_name → the joined supplier name
```

Multiple levels of nesting:

```typescript
fields: {
  category: { parent: { name: true } },  // group by category.parent.name
}
```

## Combined with Where & OrderBy

Filter before grouping and sort the grouped results:

```typescript
const result = await service.findAllGrouped(context, {
  groupBy: {
    fields: { category: true },
    aggregates: [
      { field: 'price', function: AggregateFunctionTypes.AVG, alias: 'avgPrice' },
      { field: 'id', function: AggregateFunctionTypes.COUNT, alias: 'count' },
    ],
  },
  where: {
    active: true,
    createdAt: { _gte: new Date('2024-01-01') },
  },
  orderBy: [{ category: 'ASC' }],
  pagination: { page: 1, limit: 10 },
});
```

## REST API

Pass the `groupBy` config as a JSON query parameter:

```
GET /products/grouped?groupBy={"fields":{"category":true},"aggregates":[{"field":"price","function":"AVG","alias":"avgPrice"}]}&pagination={"page":1,"limit":10}&where={"active":true}
```

Response:

```json
{
  "groups": [
    {
      "key": { "category": "Electronics" },
      "aggregates": { "avgPrice": 250.75 }
    },
    {
      "key": { "category": "Books" },
      "aggregates": { "avgPrice": 18.50 }
    }
  ],
  "pagination": {
    "total": 2,
    "count": 2,
    "page": 1,
    "pageCount": 1,
    "hasNextPage": false,
    "hasPreviousPage": false
  }
}
```

## GraphQL

Define `GroupByArgs` and a `GroupedArgsType` for your resolver:

```graphql
query {
  productsGrouped(
    groupBy: {
      fields: { category: true }
      aggregates: [
        { field: "price", function: AVG, alias: "avgPrice" }
        { field: "id", function: COUNT, alias: "productCount" }
      ]
    }
    pagination: { page: 1, limit: 10 }
  ) {
    groups {
      key
      aggregates
    }
    pagination {
      total
      page
      pageCount
      hasNextPage
      hasPreviousPage
    }
  }
}
```

## Controller / Resolver Configuration

Enable `findAllGrouped` in your structure's operations and provide the
appropriate grouped args type:

**REST Controller:**

```typescript
const controllerStructure = CrudControllerStructure({
  ...serviceStructure,
  serviceType: ProductsService,
  groupByArgsType: GroupedProductArgsRest,
  operations: {
    findAll: true,
    findOne: true,
    findAllGrouped: true,
  },
});

@Controller('products')
export class ProductsController extends CrudControllerFrom(controllerStructure) {}
```

**GraphQL Resolver:**

```typescript
const resolverStructure = CrudResolverStructure({
  ...serviceStructure,
  serviceType: ProductsService,
  groupByArgsType: GroupedProductArgsGraphQL,
  operations: {
    findAll: true,
    findOne: true,
    findAllGrouped: true,
  },
});

@Resolver(() => Product)
export class ProductsResolver extends CrudResolverFrom(resolverStructure) {}
```

## Soft Deletion Awareness

`findAllGrouped` automatically excludes soft-deleted records from aggregations
when the entity has a `deletedAt` column. No additional configuration needed.
